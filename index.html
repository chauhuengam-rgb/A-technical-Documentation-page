Introduction

JavaScript is a cross-platform, object-oriented scripting language.

It is a small and lightweight language.

var x = 5;
JavaScript and Java

JavaScript and Java are similar in some ways but fundamentally different.

The JavaScript language resembles Java but does not have Java's static typing.

console.log("Hello Java");
  • Client-side
  • Server-side
  • Dynamic typing
  • Object-oriented
  • Scripting language
Hello world

To get started with writing JavaScript, open the Console.

Type "Hello World" to see the basic output of the language.

alert("Hello World");
Variables

You use variables as symbolic names for values in your application.

The names of variables, called identifiers, conform to certain rules.

A JavaScript identifier must start with a letter, underscore (_), or dollar sign ($).

let myValue = 10;
Data types

The latest ECMAScript standard defines eight data types.

Six data types are primitives: Boolean, Null, Undefined, Number, String, Symbol.

There is also a BigInt type for very large integers.

typeof 42; // "number"
